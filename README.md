# Golden Ring Donuts — Mock Website

A complete, single-page mock website for **Golden Ring Donuts**, a fictional local donut shop in San Antonio, TX. Built as a lightweight static site — no frameworks, no build step.

## Files

- `index.html` — the single-page site: header with navigation, hero section, a menu of 7 donuts with prices, an about section, hours & location, and a footer.
- `style.css` — all styling for the site (layout, cards, responsive breakpoints).

## Features

- Responsive grid layout for the menu
- Sticky header navigation with anchor links
- Warm, donut-shop-inspired color palette

## Running locally

Just open `index.html` in any modern browser, or serve the folder with any static file server (e.g. `npx serve .`).

> This is a fictional demo site. No real business data is represented.
